# Security

Nymira is a testnet project with test funds. The circuits have had no independent review, and [THREAT_MODEL.md](THREAT_MODEL.md) lists what each party can see and do.

To report a vulnerability, email nymiralabs@proton.me. Please do not open a public issue for one. Include what you found, the file or endpoint, and steps to reproduce it.

In scope: `contracts/vault`, `crates/`, `web/`, `mcp/`, and the deployed testnet vault `vault.nymira.testnet`, the operator and the web app at <https://nymira.pages.dev>. Out of scope: NEAR AI Cloud, NEAR, Circle, Cloudflare and other third parties, and denial of service against the operator's home machine.

We read every report. This is a small team and there is no bounty.
